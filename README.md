# Data Folder

All data in this repository is **100% synthetic** and generated by
`data/synthetic_data_generator.py`. It contains no real company,
employee, or business information. Names of the company, factories,
departments, machines, and employees are fictional.

- `raw/` — generated CSVs with deliberately planted quality issues.
- `processed/` — cleaned and validated outputs used by SQL/Power BI.

Do not place any real or confidential data in this folder.
